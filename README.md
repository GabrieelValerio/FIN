# FIN — Gerenciador Interativo de Fichas e Campanhas

Uma plataforma gratuita para criação, gerenciamento e organização de fichas de personagens e campanhas de RPG.

O FIN nasceu com uma ideia simples: tornar mais fácil para qualquer pessoa organizar suas campanhas, gerenciar personagens e reunir as informações necessárias para suas aventuras em um único lugar.

Seja você um mestre organizando uma campanha com seus amigos ou um jogador que deseja manter suas fichas sempre acessíveis, o FIN foi desenvolvido para facilitar essa experiência.

## ✨ Acesse e utilize gratuitamente

Você não precisa baixar ou instalar nada para começar!

Utilize a versão hospedada e mantida pelo desenvolvedor para criar e gerenciar suas próprias campanhas.

**🌐 Acessar o FIN:** https://gabrieelvalerio.github.io/FIN/index.html

A proposta é permitir que qualquer pessoa utilize a plataforma gratuitamente, sem precisar manter um servidor ou configurar um ambiente próprio.

## 🎲 O que é possível fazer?

O FIN está em desenvolvimento e busca reunir ferramentas para facilitar o gerenciamento de campanhas e personagens.

Entre suas funcionalidades estão:

- Gerenciamento de fichas de personagens.
- Organização de campanhas.
- Acesso às informações dos personagens.
- Ferramentas para auxiliar mestres e jogadores.
- Gerenciamento centralizado das informações das campanhas.

*As funcionalidades disponíveis podem variar conforme a versão da plataforma.*

## 🏠 Tenha sua própria versão

Prefere ter controle total sobre sua instalação?

O FIN também é um projeto disponibilizado para que outras pessoas possam baixar, configurar e hospedar suas próprias versões.

Você pode utilizar o código-fonte para colocar sua própria instância no ar, sem depender da hospedagem mantida pelo desenvolvedor.

Isso permite que você:

- Tenha seu próprio ambiente.
- Gerencie sua própria instalação.
- Configure o projeto de acordo com suas necessidades.
- Mantenha suas campanhas em uma instância sob seu controle.
- Ajudar o projeto a evoluir.

## 💡 Filosofia do projeto

O FIN é desenvolvido com o objetivo de tornar ferramentas de gerenciamento de RPG mais acessíveis.

Acredito que organizar uma campanha não deveria exigir ferramentas caras, configurações complicadas ou conhecimentos avançados de tecnologia.

Por isso, a proposta é manter uma versão pública e gratuita da plataforma, enquanto o código-fonte permanece disponível para quem deseja estudar, modificar ou hospedar sua própria instalação.
